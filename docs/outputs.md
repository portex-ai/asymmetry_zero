# Outputs

This guide describes the output files generated by `portex-eval` evaluation runs.

## Output Directory Structure

Each evaluation run creates an output directory:

```
eval_runs/<run_id>/
├── eval_log.json           # Inspect AI evaluation log
├── reports/
│   ├── eval_level.csv      # Aggregate evaluation metrics
│   ├── task_level.csv      # Per-task scores
│   ├── criterion_level.csv # Per-criterion breakdown
│   └── judgement_level.csv # Individual judge verdicts
└── rl_rewards.txt          # Task-level rewards for RL
```

## Inspect AI Log

The `eval_log.json` (or `.eval`) file is an Inspect AI evaluation log containing:

- Full evaluation metadata
- Model configurations
- All samples with prompts and responses
- Scoring details and judge outputs
- Timing and resource usage

Use Inspect AI tools to analyze:

```python
from inspect_ai.analysis import eval_df, samples_df

# Load from EvalResults
samples = samples_df(results.logs)
evals = eval_df(results.logs)

# Or load directly
from inspect_ai import read_eval_log
log = read_eval_log("./eval_runs/.../eval_log.eval")
```

## CSV Reports

### eval_level.csv

Aggregate metrics for the entire evaluation.

| Column | Description |
|--------|-------------|
| `eval_id` | Evaluation identifier |
| `model` | Candidate model name |
| `bundle` | Bundle name |
| `total_tasks` | Number of tasks evaluated |
| `mean_score` | Mean score across all tasks |
| `pass_rate` | Percentage of tasks that passed threshold |
| `timestamp` | Evaluation timestamp |

### task_level.csv

Per-task scores and pass/fail status.

| Column | Description |
|--------|-------------|
| `task_id` | Task identifier |
| `score` | Final score (0-100) |
| `passed` | Whether the task passed its threshold |
| `pass_threshold` | Required score to pass |
| `num_criteria` | Number of grading criteria |

### criterion_level.csv

Breakdown of scores by criterion for tasks with custom grading criteria.

| Column | Description |
|--------|-------------|
| `task_id` | Task identifier |
| `criterion_id` | Criterion identifier |
| `criterion_name` | Criterion name |
| `score` | Score for this criterion (0-100) |
| `weight` | Weight of this criterion |
| `weighted_score` | Score × weight / 100 |

### judgement_level.csv

Individual verdicts from each judge model.

| Column | Description |
|--------|-------------|
| `task_id` | Task identifier |
| `judge_model` | Judge model name |
| `criterion_id` | Criterion identifier (if applicable) |
| `verdict` | Judge's verdict (pass/fail/score) |
| `rationale` | Judge's reasoning |

## Loading Reports

Use the `reports` module to load CSV files:

```python
from portex_eval import reports

# Load from EvalResults
eval_df = reports.load(results.reports.eval_level)
task_df = reports.load(results.reports.task_level)
criterion_df = reports.load(results.reports.criterion_level)
judgement_df = reports.load(results.reports.judgement_level)

# Basic pandas operations
print(task_df["score"].mean())
print(task_df[task_df["passed"] == True])
```

## RL Rewards File

The `rl_rewards.txt` file contains task-level reward scores for reinforcement learning pipelines.

### Format

Plain text, one line per task:

```
<task_id> <score>
```

Where:
- `task_id` - The task identifier string
- `score` - The final score on a 0-100 scale

### Example

```
geography-001 100.0
history-001 87.5
science-001 50.0
```

### Reading Rewards

```python
# Direct file reading
rewards = {}
with open(results.rewards) as f:
    for line in f:
        task_id, score = line.strip().split()
        rewards[task_id] = float(score)

# Or from task_level.csv
from portex_eval import reports
task_df = reports.load(results.reports.task_level)
rewards = dict(zip(task_df["task_id"], task_df["score"]))
```

### Using in RL Pipelines

The rewards file is designed for integration with RL training:

```python
def load_rewards(path):
    """Load rewards for RLHF/DPO training."""
    rewards = {}
    with open(path) as f:
        for line in f:
            parts = line.strip().split(maxsplit=1)
            if len(parts) == 2:
                task_id, score = parts
                # Normalize to 0-1 for reward modeling
                rewards[task_id] = float(score) / 100.0
    return rewards

# Use in training loop
rewards = load_rewards("./eval_runs/.../rl_rewards.txt")
for sample in training_data:
    reward = rewards.get(sample.task_id, 0.0)
    # Apply reward to training
```

## EvalResults Object

The `eval()` function returns an `EvalResults` object with all output paths:

```python
results = eval(...)

# Access paths
print(results.run_id)          # "20240115_143022_abc123"
print(results.output_dir)      # "/path/to/eval_runs/..."
print(results.logs)            # ["/path/to/eval_log.json"]
print(results.rewards)         # "/path/to/rl_rewards.txt"
print(results.reports.eval_level)      # "/path/to/reports/eval_level.csv"
print(results.reports.task_level)      # "/path/to/reports/task_level.csv"
print(results.reports.criterion_level) # "/path/to/reports/criterion_level.csv"
print(results.reports.judgement_level) # "/path/to/reports/judgement_level.csv"
```

All paths are absolute after calling `eval()`.
